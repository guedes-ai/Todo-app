# App de Lista de Tarefas

Projeto prático de front-end desenvolvido com React e Styled-Components.

## Funcionalidades

- Adicionar tarefas
- Marcar tarefa como concluída / ativa
- Remover tarefas
- Filtrar por status (Todas, Ativas, Concluídas)
- Alternar entre tema claro e escuro

## Tecnologias

- React 18
- Styled-Components v6
- Vite

## Estrutura de arquivos

```src/
├── components/

│   └── components/

│       └── Tarefa.styles.js

```

## Como rodar

Clone o repositório:
```bash
git clone https://github.com/guedes-ai/Todo-app.git
```

Instale as dependências:
```bash
npm install
```

Rode o projeto:
```bash
npm run dev
```

Acesse em: [http://localhost:5173](http://localhost:5173/)
